# EventService

Проект «Панель организатора: Учет масштабных мероприятий» в рамках учебной практики по модулю ПМ.03.

## Описание
Приложение на Python (Tkinter) для авторизации организаторов и автоматического расчета финансового оборота (прогноза выручки) масштабных мероприятий на основе базы данных.
